# Neue Fotos hier ablegen

Einfach die Bilddateien in **diesen Ordner** kopieren — der Name ist egal
(`IMG_4711.jpg`, `WhatsApp Bild.jpeg`, alles recht).

Danach im Chat kurz „Fotos liegen im Ordner" schreiben. Dann werden sie

1. angeschaut und verständlich benannt,
2. auf Webgröße verkleinert (unter 300 KB je Datei),
3. an die richtige Stelle der Website einsortiert,
4. in `fotos/` als Original abgelegt — und damit beim Veröffentlichen
   mitgenommen.

## Diese drei Plätze warten gerade auf ein Foto

| Platz auf der Website              | Zieldatei                              |
|------------------------------------|----------------------------------------|
| Projekte — Gartenpflege            | `../projekte/gartenpflege.jpg`         |
| Projekte — Ladenlokal „OICHI"      | `../projekte/ladenbau-oichi.jpg`       |
| Fußzeile — Mitarbeiter, Holzterrasse | `../footer/handwerker.jpg`           |

Wer die Dateien lieber selbst benennt: einfach direkt unter diesen Zielnamen
speichern, dann erscheinen sie sofort auf der Seite — im Code ist nichts zu
ändern.
